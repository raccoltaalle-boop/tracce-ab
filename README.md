# Tracce A→B

App Android per registrare tracce GPS (scooter, bici, auto) anche a schermo spento e confrontare i tempi di percorrenza tra due luoghi.

- **Installa l'ultima versione:** [tracce-ab.apk](https://github.com/raccoltaalle-boop/tracce-ab/raw/dist/tracce-ab.apk)
- Ogni push su `main` viene compilato da GitHub Actions e pubblicato nel branch `dist`; l'app si aggiorna da sola all'avvio.
- Dettagli in [LEGGIMI.txt](LEGGIMI.txt).
